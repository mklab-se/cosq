# Cosq 1.0 Phase 3 — Schema Cards + Ask Implementation Plan

> Executed inline. Spec §6.

## Tasks
1. **cosq-core `schema_card.rs`**: `SchemaCard { container, database, built_at, partition_key, fields: Vec<FieldInfo{path,types,example,values}>, relationships: Vec<Relationship{field,references,confidence}>, vector: Option<(path,dims,distance)>, full_text: Vec<String>, embed_node: Option<String> }`;
   YAML round-trip; cache path `~/.cosq/schema/<profile>/<db>/<container>.yaml`
   (project `./.cosq/schema/...` wins on load); `is_stale(ttl)`; `COSQ_SCHEMA_TTL_DAYS`.
2. **`cosq schema` command** (`commands/schema.rs`): load cached else build:
   sample `SELECT TOP 3 * FROM c` (+ meta from get_container) → ailloy
   `json_schema` structured card synthesis (fields/relationships) → merge
   policies from meta → save + print human-readably. `--refresh`, `--json`.
   AI-off fallback: mechanical card (fields/types from samples, no
   relationships/descriptions).
3. **`cosq ask` command** (`commands/ask.rs`): card (auto-build) → ailloy
   json_schema `{sql, parameters:[{name,value}], explanation, confidence}` →
   confidence/fan-out confirm (unless --yes) → execute via query engine →
   results stdout, SQL+explanation stderr. `--save <name>` writes a stored
   query; `--sql-only`. `AskMemory { exchanges: Vec<(question, sql, result_note)> }`
   parameter for shell follow-ups.
4. **Shell wiring**: `?` → ask with per-session memory (last 5); `:schema` prints card.
5. **generate refactor (minimal)**: `queries generate` samples via schema cards
   and parses via response_format json_schema; conversation loop retained.
6. Tests: card YAML round-trip + staleness + path precedence; ask verdict
   parsing + prompt content; mechanical-card builder from fixture docs.
   Live: schema + ask against enterprise_memory (read-only).
